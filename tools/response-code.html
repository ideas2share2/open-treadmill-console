Legacy console response calculator

For the owner-service challenge prompt on compatible older consoles. Keep the belt stopped and the safety key removed.

This file works offline. It makes no network requests, stores nothing and cannot connect to or control a treadmill. Firmware compatibility is not guaranteed.

The modes agree for most inputs. They differ on rare signed-integer edge cases; see the algorithm notes in the repository. Do not assume either mode works on every firmware.

Enter the result locally on your own console. This computes the legacy method only; it cannot restore a service menu that the firmware does not expose.
